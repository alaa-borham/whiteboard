# 🖊️ الوايت بورد

لوحة عمل مستقلة تعمل في المتصفح مباشرةً — بلا تسجيل دخول وبلا خادم.

**الرابط:** https://alaa-borham.github.io/whiteboard/

## الأوضاع الثلاثة
- ✏️ **رسم حر** — ألوان، سماكة قلم، ممحاة، تراجع، مسح، وحفظ الرسمة كصورة PNG.
- 📋 **لوحة مهام (Kanban)** — أعمدة تُضاف/تُحذف/تُسمّى، وبطاقات تُسحب بين الأعمدة وتُحرَّر بالنقر.
- 🗒️ **ملاحظات لاصقة** — ملوّنة، تُسحب وتُكتب وتُحذف بحرية.
- 🔷 **مخططات (Diagrams)** — مكتبة أشكال (مستطيل، دائرة، معيّن، متوازي أضلاع، سداسي، سهم، بداية/نهاية) تُسحب وتتغيّر أحجامها وتُكتب بداخلها، وتُربط بأسهم تتبع الأشكال. مع ألوان تعبئة/حدود، تراجع، وتصدير PNG و SVG. تشبه أدوات draw.io المبسّطة.

## المزايا
- ملف واحد فقط (`index.html`) — كل شيء مضمّن (HTML/CSS/JS).
- حفظ تلقائي محلي في المتصفح (localStorage) مع تذكّر آخر وضع مفتوح.
- يعمل على الجوال واللمس، وواجهة عربية RTL.
