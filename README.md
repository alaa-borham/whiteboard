# 🖊️ الوايت بورد

لوحة عمل مستقلة تعمل في المتصفح مباشرةً — بلا تسجيل دخول وبلا خادم.

**الرابط:** https://alaa-borham.github.io/whiteboard/

## الأوضاع الثلاثة
- ✏️ **رسم حر** — ألوان، سماكة قلم، ممحاة، تراجع، مسح، وحفظ الرسمة كصورة PNG.
- 📋 **لوحة مهام (Kanban)** — أعمدة تُضاف/تُحذف/تُسمّى، وبطاقات تُسحب بين الأعمدة وتُحرَّر بالنقر.
- 🗒️ **ملاحظات لاصقة** — ملوّنة، تُسحب وتُكتب وتُحذف بحرية.
- 🔷 **مخططات (Diagrams)** — محرّر مخططات يشبه draw.io:
  - مكتبة أشكال (مستطيل، دائري، دائرة، بداية/نهاية، معيّن، متوازي أضلاع، سداسي، سهم).
  - سحب لتحريك الأشكال، مقابض لتغيير الحجم، **كتابة مباشرة داخل الشكل** بالنقر المزدوج (بلا نوافذ منبثقة، متعدد الأسطر بـ Shift+Enter).
  - ربط بأسهم تتبع الأشكال، مع أنواع للسهم: مستقيم/منحني/متعامد، رأس نهاية/طرفين/بدون، وخط متصل/متقطع.
  - ألوان تعبئة وحدود، نسخ/لصق (Ctrl+C/V)، تراجع (Ctrl+Z)، حذف.
  - **استيراد صور** كعناصر داخل المخطط تُحرَّك ويُتحكَّم في حجمها.
  - تحكّم في **لون نص** الشكل، و**لون وسماكة** خط الربط بين الأشكال.
  - تصدير المخطط: **PNG**، **PDF**، **SVG**، وحفظ/استيراد **JSON**، مع تكبير/تصغير.
  - **معاينة قبل الطباعة** ثم طباعة، مع **Ctrl+نقر** لتحديد أشكال معيّنة وطباعتها وحدها.
  - تغيير **لون خلفية البورد** و**نمط الخلفية** (نقاط/مربعات/سادة).
  - منافذ ربط خضراء على **كل أضلاع** الشكل، ومنحنيات أسهم **ناعمة (S)**.

## المزايا
- ملف واحد فقط (`index.html`) — كل شيء مضمّن (HTML/CSS/JS).
- حفظ تلقائي محلي في المتصفح (localStorage) مع تذكّر آخر وضع مفتوح.
- يعمل على الجوال واللمس، وواجهة عربية RTL.
